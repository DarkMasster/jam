# 48-часовой пайплайн

## Роли

Один человек может совмещать несколько ролей, но у каждого решения должен быть
один финальный владелец.

### Продюсер / режиссёр

- утверждает концепцию и приоритеты;
- защищает scope и принимает решения `делаем / позже / вырезаем`;
- останавливает добавление новых механик после 24-го часа.

### Гейм-дизайнер / scope keeper

- формулирует core loop, победу, поражение и правила;
- превращает идеи в проверяемые задачи;
- предлагает вырезать всё, что не усиливает основной цикл.

### Технический архитектор / интегратор

- определяет минимальные контракты и границы параллельной работы;
- владеет общей сборкой и конфликтными ресурсами;
- интегрирует проверенные feature-ветки в `main`.

### Исполнитель задачи

- реализует одну небольшую задачу в своей ветке;
- не выходит за разрешённую область файлов;
- проверяет критерии готовности и оставляет handoff.

### Контент и polish

- создаёт ассеты по утверждённому списку;
- улучшает читаемость, звук, UI и game feel после готовности полного цикла;
- не вводит новую механику через контент.

### Build reviewer

Это не постоянная QA-роль. Она включается на 10–15 минут после часов 12, 24 и 42
и возвращает максимум три замечания:

1. Что мешает закончить игру?
2. Что мешает понять цель или управление?
3. Что сильнее всего портит впечатление?

Только блокирующая ошибка может остановить текущую разработку.

## Конвейер задачи

```text
Продюсер утверждает цель
→ дизайнер сужает scope
→ интегратор фиксирует контракт и владельца
→ исполнитель работает в feature-ветке
→ исполнитель проверяет и заполняет handoff
→ build reviewer даёт до 3 замечаний на контрольной точке
→ интегратор выполняет merge в main
→ STATE/BACKLOG обновляются
```

## План времени

| Время | Результат | Запрещённый риск |
|---|---|---|
| 0–3 ч | Концепция, core loop, Must/Cut, владельцы | Несогласованные прототипы |
| 3–12 ч | Плохой, но играбельный вертикальный прототип | Графика до проверки loop |
| 12–24 ч | Полный цикл с победой, поражением и рестартом | Новые большие системы |
| 24–34 ч | Контент, feedback, звук, UI, баланс | Новые основные механики |
| 34–42 ч | Исправление блокеров и финальный билд | Рефакторинг ради чистоты |
| 42–46 ч | Страница игры, скриншоты, инструкции | Изменение архитектуры |
| 46–48 ч | Резерв и отправка | Любые необязательные фичи |

## Контрольные точки

На часах 12, 24, 34 и 42 интегратор:

1. собирает проект из `main`;
2. записывает hash и результат в `STATE.md`;
3. проводит короткий smoke test;
4. обновляет P0 в `BACKLOG.md`;
5. просит продюсера явно вырезать задачи, не помещающиеся в оставшееся время.

## Формат постановки задачи

Каждая задача создаётся копированием `tasks/TEMPLATE.md`. Критерии готовности,
область файлов, владелец, ветка и способ проверки обязательны до начала работы.
