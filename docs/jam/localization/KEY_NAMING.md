# Имена ключей локализации

Формат: строчные сегменты через точку, без языка и номера версии.

- UI: `ui.<screen>.<element|state>`, например `ui.main.continue`.
- Эпизодный HUD: `hud.<element|state>` внутри таблицы эпизода.
- Сюжет: `<act>.<sequence>.<entry>.(speaker|text)`.
- Действия: `action.<verb_or_choice>`.
- Состояния: `status.<event>` и `phase.<phase>`.
- Предметы и персонажи: `item.<id>`, `enemy.<id>`, `choice.<id>`.

Ключ описывает смысл, а не текущую формулировку. Переименование ключа — изменение
контракта: обновляются код, графы, storyboard assets и таблицы одним commit.
Параметры используют `{0}`, `{1}` и должны совпадать во всех языках.
