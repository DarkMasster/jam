# Выбор персонажа и сохранение прогресса

- Владелец: `интегратор`
- Статус: `Done`
- Приоритет: `P0`
- Ветка: `feature/main-menu`
- Зависимости: `Main`, `GameSaveService`, `Input System`, `uGUI`
- Лимит времени: `3 часа`

## Цель

Новая игра открывает выбор одного из трёх героев; остановленная сессия продолжается
с последней сцены и checkpoint, а финал открывается после трёх линий.

## Контекст

Эпизодные сцены и `Finale` ещё не созданы. Для проверки выбранная линия открывает
`SampleScene`, не теряя `CharacterId`.

- [x] Новая игра, выбор героя и продолжение после остановки проверены.
- [x] Финал остаётся закрыт при `2/3` и открывается при `3/3`.
- [x] Документация памяти обновлена.

## Разрешённая область

- Файлы или директории, которые можно менять: `Assets/Game/Core/**`,
  `Assets/Game/Scenes/CharacterSelect.unity`, Build Settings, `docs/jam/**`
- Общие ресурсы, владельцем которых является исполнитель: `CharacterSelect`,
  сохранение, Build Settings

## Не менять

- Файлы, сцены, настройки и контракты вне задачи.

## Как проверить

Запустить `Main`, нажать «Новая игра», выбрать героя. После остановки Play Mode
снова запустить `Main` и нажать «Продолжить»: должна открыться сохранённая сцена с
тем же активным героем. Три вызова завершения разных линий открывают `Finale`.
