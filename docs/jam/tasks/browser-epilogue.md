# Browser epilogue

## Scope

- Открывать опубликованный эпилог после завершения линий Office и Photo.
- Не учитывать Drive в условии разблокировки.
- Добавить заблокированную кнопку эпилога в `CharacterSelect`.

## Acceptance

- [x] `EpilogueUnlocked` требует только Office и Photo.
- [x] Первый переход в разблокированное состояние автоматически открывает URL.
- [x] Кнопка меню заблокирована до выполнения условия и доступна после него.
- [x] URL отвечает HTTP 200.

## Handoff

- Единый URL и проверка доступа находятся в `EpilogueService`.
- Office отмечается завершённым после HotelArrival, Photo — после outro.
- Автооткрытие срабатывает только один раз, когда завершена вторая требуемая линия;
  дальнейшие открытия выполняются кнопкой в `CharacterSelect`.
