# Unity MCP token policy

## Задача

Зафиксировать в проектных инструкциях правила, которые уменьшают число Unity MCP
round trips и объём возвращаемого контекста, а автоматические проверки переводят
на Unity Test Framework.

## Ветка

`feature/unity-mcp-token-policy`

## Разрешённая область

- `AGENTS.md`
- `docs/jam/tasks/unity-mcp-token-policy.md`

## Не менять

- Игровой код, тесты, сцены, prefab, Unity YAML, настройки проекта и публичные API.
- Существующие task-файлы и статусы игровых задач.

## Критерии готовности

- В `AGENTS.md` закреплены пакетные Unity-операции и точечная инспекция.
- Ограничены чтение Console, stack trace и повторные проверки.
- EditMode- и PlayMode-прогоны выполняются через Unity Test Framework с узкими
  фильтрами, а ручной Play Mode оставлен только для необходимой визуальной проверки.
- Правила не зависят от необязательных возможностей конкретной версии MCP-сервера.

## Проверка

- Просмотреть итоговый diff.
- Выполнить `git diff --check`.
