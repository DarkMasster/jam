- Статус: `Todo`
- Приоритет: `P0/P1/P2`
- Ветка: `feature/task-name`
- Зависимости: `нет/TBD`
- Лимит времени: `TBD`

## Цель

Один наблюдаемый результат задачи.

## Контекст

## Критерии готовности

- [ ] Результат доступен в игре или сборке.
- [ ] Основной сценарий проверен.
- [ ] Нет новой блокирующей ошибки.
- [ ] Документация памяти обновлена при необходимости.
