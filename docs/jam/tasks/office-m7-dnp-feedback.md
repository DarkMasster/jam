## Цель

Добавить world-space feedback только для подтверждённых событий офисного забега:
засчитанного урона, разрушения и подбора, не меняя авторитетное игровое состояние.

## Критерии готовности

- [x] Успешный урон креслу, боссу или игроку показывает `-1` над целью.
- [x] Разрушение принтера показывает `СЛОМАНО` над объектом.
- [x] Подбор клавиатуры, ноутбука и кружки показывает отлетающий текст над героем.
- [x] Сбор ноутбука и кружки вместе даёт отдельное редкое уведомление.
- [x] Слабые, повторные и не засчитанные столкновения не создают popup.
- [x] HUD, SFX, частицы и дрожь камеры не регрессируют.

## Как проверить

1. Пересобрать сцену через `Jam/Office/Rebuild Prologue Office`.
2. Проверить подтверждённые попадания по принтеру, креслу, боссу и герою.
3. Проверить автоподбор клавиатуры, ноутбука и кружки.
4. Убедиться, что слабое столкновение не показывает popup.
5. Пройти scene validation и целевые Unity-тесты; проверить Console.
