# M1A — предмет, бросок и простое разрушение

- Владелец: `ИИ-агент`
- Статус: `Done`
- Приоритет: `P0`
- Ветка: `feature/office-unity-scene`
- Зависимости: `общий InputSystem_Actions (карта Office ещё не создана интегратором)`
- Лимит времени: `2 часа`

## Цель

На существующей сцене `Prologue_Office` замкнуть первый action-loop офиса: один
переносимый предмет с автоматическим выбором и подбором, бросок по `Primary`,
короткий lockout повторного подбора и один подготовленный объект с состояниями
`Intact → Broken`.

## Контекст

`M0` даёт стабильный greybox-маршрут. `DEVELOPMENT_SPEC.md` фиксирует, что в
Unity-версии отдельной кнопки подбора нет: свободные руки автоматически берут
подходящий предмет в небольшой зоне перед героем, выбранная цель заранее
подсвечивается, занятые руки не заменяют предмет, а после броска предмет получает
короткую блокировку повторного подбора. Разрушение ограничено подготовленными
состояниями без свободной фрагментации.

Карта `Office` в общем input asset ещё не создана. Как и `Player/Move` в `M0`,
`Primary` временно берётся из существующего `Player/Attack` через настраиваемую
ссылку; общий asset не изменяется.

## Критерии готовности

- [x] Один лёгкий предмет автоматически выбирается перед героем и показывает цель
      подбора.
- [x] Занятые руки не заменяют текущий предмет новым.
- [x] `Primary` бросает предмет; краткий lockout не даёт подобрать его в том же
      кадре.
- [x] Один подготовленный объект проходит состояния `Intact → Broken` и даёт
      однозначный визуальный feedback.
- [x] Существующие pickups, маршрут и закрытый `EXIT` не регрессируют.
- [x] Console не содержит новых ошибок или предупреждений офисного среза.
- [x] `OFFICE_ROADMAP.md` обновлён до `Handoff`.

## Как проверить

Открыть `Assets/Game/Scenes/Prologue_Office.unity`, запустить Play Mode. Подойти к
клавиатуре на столе: цель подсвечивается заранее, затем предмет автоматически
оказывается в руках. Пройти мимо другой клавиатуры — она не заменяет текущую.
Нажать `Primary` (ЛКМ) рядом с принтером: предмет улетает вперёд, принтер
переходит в `Broken` со вспышкой, HUD показывает счётчик. Сразу подойти к
брошенному предмету — он не подбирается до конца lockout.
