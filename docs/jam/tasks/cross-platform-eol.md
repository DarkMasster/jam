# Кроссплатформенная нормализация текстовых файлов

- Владелец: `Codex`
- Статус: `Done`
- Приоритет: `P0`
- Ветка: `fix/cross-platform-eol`
- Зависимости: `нет`
- Лимит времени: `30 минут`

## Цель

Устранить ложные Git diff между Windows и macOS, сохранив корректный формат
UnityYAML.

## Контекст

Unity повторно сериализовала пустое поле `m_Name` с завершающим пробелом. Это не
изменение значения и не смена окончания строк.

## Критерии готовности

- [x] Текстовые файлы нормализуются в LF на Windows и macOS.
- [x] UnityYAML остаётся текстовым и использует Unity Smart Merge.
- [x] Допустимый завершающий пробел UnityYAML не считается whitespace-ошибкой.
- [x] Текущая сериализация Project Auditor сохранена без ручного форматирования.

## Разрешённая область

- Файлы или директории, которые можно менять: `.gitattributes`,
  `ProjectSettings/ProjectAuditorSettings.asset`, этот task-файл.
- Общие ресурсы, владельцем которых является исполнитель: Git-атрибуты текстовых
  файлов в рамках исправления.

## Не менять

- Игровые сцены, код, публичные контракты и остальные настройки проекта.

## Как проверить

Запустить `git check-attr text eol whitespace --` для UnityYAML и обычного
текстового файла, затем `git diff --check`. Ожидается `text`, `eol: lf`,
`whitespace: -blank-at-eol` для UnityYAML и отсутствие ошибок diff.
