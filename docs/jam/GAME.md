# Ядро игры

Статус: утверждены тема, структура трёх актов и цель Пролога; сейчас проектируется Пролог.

## Техническая база

- Движок: Unity 6000.5.3f1.
- Render Pipeline: Universal Render Pipeline 17.5.0.
- Input: Unity New Input System 1.19.0 используется во всей игре; legacy Input
  Manager не используется.
- Репозиторий: Git с Git LFS.

## Подтверждённый формат

- Жанр: сюжетная игра.
- Три игровых персонажа с отдельными экспозициями и мини-играми.
- Три акта: Пролог, Основа, Финал.
- Стартовые города: Москва, Екатеринбург и Санкт-Петербург.
- Все три линии начинаются в один день на фоне начала войны в 2022 году.
- Игрок сам выбирает порядок прохождения персонажей.
- Тема джема: `Reflection + Momentum`.
- Полная игра рассчитана на 3–4 часа; джем-билд фокусируется на Прологе.
- Каждая линия Пролога длится 5–10 минут; суммарный целевой объём — 15–30 минут.
- Подробности персонажей, актов и референсов: `STORY.md`.
- Нерешённые сюжетные вопросы: `QUESTIONS.md`.
- Риски и меры сокращения scope: `PREMORTEM.md`.

## Питч

Одно предложение: после начала полномасштабной войны России против Украины в 2022
году три незнакомых человека теряют привычную опору, проходят через трудности
эмиграции и учатся превращать рефлексию о прошлом в движение к новой жизни.

## Core loop

Рабочая гипотеза:

1. Cutscene ставит героя перед потерей контроля или источника безопасности.
2. Игрок проходит короткую жанровую мини-игру, выражающую способ выживания героя.
3. Результат меняет следующую сцену и подводит героя к цене компромисса.

## Must have

- Игрок понимает цель без устного объяснения разработчика.
- Есть полный цикл: старт → игра → победа или поражение → рестарт.
- Есть собираемый и запускаемый билд.

## Можно добавить после полного цикла

- Звук и визуальная обратная связь.
- Небольшой объём контента и балансировка.
- Экран меню и короткое обучение.

## Не делаем без отдельного решения продюсера

- Новую основную механику после 24-го часа.
- Сложную мета-прогрессию, мультиплеер или несколько больших уровней.
- Технический рефакторинг, не устраняющий текущий риск или блокер.
