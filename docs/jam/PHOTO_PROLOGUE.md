# Production-пролог персонажа 3

- Статус: `реализуется`
- Версия контракта: `1.0`
- Save schema: `3`
- Сцена: `Assets/Game/Scenes/Prologue_Photo.unity`
- Ветка: `feature/photo-prologue`

Этот документ уточняет раздел 7 `DEVELOPMENT_SPEC.md` по прямому решению
продюсера от 2026-08-02. При расхождении для Photo production-flow действует он.

## Цель и длительность

Игрок проходит три сцены за 7–15 минут: Неоновая комната → Подъезд → Аэропорт.
Героиня теряет работу, сталкивается с секретностью и конфликтом с матерью, выбирает
способ показать военную реальность и уезжает через Дубай на Бали.

## Авторитетное состояние

- `honesty` и `recognition` начинаются с `20`, ограничены диапазоном `0..100`.
- `PhotoProloguePath`: `Undecided`, `Honesty`, `Recognition`, `Balance`.
- Путь, а не числовой порог, определяет доступность реплик в аэропорту.
- `PhotoPrologueStep` восстанавливает устойчивый экран внутри checkpoint.
- Все изменения выбора идемпотентны: один экран нельзя применить повторно.

## Сцена 1 — Неоновая комната

1. «Они же не узнают…»:
   - отрицание — `0`;
   - «Они уже знают» — `+20 Recognition`;
   - «Пусть узнают» — `+20 Honesty`.
2. Первый снимок лампы:
   - честный кадр — `+20 Honesty`;
   - фильтр с крыльями — `+20 Recognition`.
3. Разговор с матерью:
   - честно сказать об увольнении и отъезде — `−20 Honesty`;
   - защитная ложь о международном проекте — `+20 Recognition`.

## Сцена 2 — Подъезд

Игрок находит повестку и бабочку в общей композиции. Затвор доступен после первой
детали, Balance требует обе.

| Публикация | Эффект | Путь |
|---|---|---|
| Маска «Крылья» | `+50 Recognition` | `Recognition` |
| Повестка без фильтра | `+50 Honesty` | `Honesty` |
| Оба объекта, завуалированно | `+25/+25` | `Balance` |

Публикация сначала атомарно фиксируется в payload, затем показывается реакция сети.

## Сцена 3 — Аэропорт

- Атмосферный снимок отражения можно сделать или пропустить; шкалы не меняются.
- `Honesty` открывает только «Обратного билета нет».
- `Recognition` открывает только защитную реплику о возвращении.
- `Balance` открывает обе реплики.
- Финал показывает штамп и режим полёта, затем запускает пропускаемый storyboard
  `photo.prologue.to_be_continued`: транзитная гостиница в Дубае и титр
  «ПРОДОЛЖЕНИЕ СЛЕДУЕТ». После завершения или пропуска `GameFlowService` сохраняет
  результат и возвращает игрока в `CharacterSelect`.

## Сохранение

Стабильные checkpoint ID не меняются:

| Checkpoint | Production-содержание |
|---|---|
| `photo.intro` | вступительный storyboard |
| `photo.explore` | выборы комнаты и поиск деталей |
| `photo.camera` | матрица публикации |
| `photo.published` | реакция сети и аэропорт |
| `photo.arrival` | завершённый пролог перед финальным storyboard и возвратом к выбору |

`PhotoCheckpointAdapter` единолично валидирует schema `3` и мигрирует v1/v2.
Незавершённый legacy-run начинает новый контент с комнаты; уже опубликованный кадр
сохраняет старый выбор и продолжается с аэропорта.

## UI и локализация

- Все runtime-экраны используют `DarkUiTheme` главного меню для панелей,
  интерактивных кнопок и карточек; мятный и розовый остаются цветами путей.
- `RenderedPortrait` расположен слева в нижней диалоговой панели и после сборки
  интерфейса переводится в последний sibling, чтобы не перекрываться Choices.

- Только TextMeshPro.
- Строки находятся в таблице `Photo`, русский и английский обязательны.
- Палитра: чёрный/бордовый фон, мятная Честность, розовое Признание, лаймовый фокус.
- Runtime presentation переключает четыре композиции по шагу: диалог с портретной
  зоной, видоискатель с сеткой и затвором, матрица из трёх карточек и итоговый экран.
- Общая структура соответствует мокапам: верхняя сцена, нижняя бордовая зона решений
  и пропорциональная лента Честность/Признание без чисел вне обучения.
- Числа шкал видны только на первом обучающем экране камеры. После обучения UI
  сообщает направление выбора словами, не раскрывая числовое состояние.
- Экран аэропортового снимка содержит явную кнопку «Не снимать».

## Dialogue Trees и звук

- Реальные NodeCanvas Dialogue Tree assets владеют разговором с матерью и
  паспортным контролем: statement → выбор → отдельный finish каждой ветки.
- `PhotoWhiteboxController` подписывается на NodeCanvas subtitle/choice events и
  показывает граф через общий TMP-интерфейс. Dialogue Tree не меняет save-state:
  выбранный индекс после callback передаётся в `PhotoPrologueRules`.
- Реплики в графах содержат стабильные ключи таблицы `Photo`, а локализация
  разрешается presentation-слоем при показе.
- Project-owned AudioCue: дождь/комната, аэропорт, затвор, дверь и паспортный
  штамп. В текущем срезе используются локально сгенерированные прототипные WAV;
  финальные записи заменяются в cue-ассетах без изменения gameplay-кода.

## Проверка MVP

- Новая игра из `Main` открывает Photo через `CharacterSelect`.
- Intro можно пропустить без расхождения состояния.
- Все три пути доходят до storyboard «Продолжение следует», а затем до
  `CharacterSelect`; пропуск storyboard даёт тот же результат.
- Balance действительно открывает обе пограничные реплики.
- Ручное сохранение и Continue не повторяют эффекты выбора.
- Миграция v2 опубликованного кадра продолжает с аэропорта.
- Console не содержит ошибок и новых предупреждений.
