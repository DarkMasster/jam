# OFFBOARDING — веб-прототип

Самостоятельная веб-демка офисного забега на Three.js. От Unity-проекта не
зависит: своя папка, свои файлы, ничего из `Assets/` не используется.

Цель — быстро пощупать core loop (momentum + разрушение + побег) и композицию
главного меню до того, как это будет собрано в Unity.

## Запуск

Нужен любой статический сервер (ES-модули не работают через `file://`):

```bash
python3 -m http.server 8123 --directory web-demos
```

Затем открыть <http://localhost:8123/office/>.

Three.js подтягивается с unpkg через importmap, поэтому при первом запуске нужен
интернет. Если понадобится офлайн — положить `three.module.js` рядом и поправить
importmap в `index.html`.

## Управление

- `WASD` / стрелки — бег
- `SPACE` — бросить коробку (если она взята в меню)
- `R` — рестарт
- `ESC` — закрыть оверлей
- В меню: клик по ноутбуку или `ENTER` — играть, `H` — handbook

## Что реализовано

- Меню как часть сцены: герой за столом, ноутбук = `PLAY`, папка = `HANDBOOK`,
  дверь с красной вывеской = `QUIT`, коробка = функциональный предмет.
- Стена с распечатками про замену сотрудников нейросетями.
- Переход в игру через переворот стола (анимация + пролёт камеры).
- Momentum: скорость растёт от разрушений и падает от простоя.
- Разрушение по схеме `Intact -> Broken -> debris`, без реальной фрагментации.
- Стеклянные перегородки поперёк этажа как ворота момента: пробиваются только
  на скорости.
- Цепные разрушения: летящие предметы и брошенная коробка ломают другие объекты.
- Дроны службы безопасности: сбивают момент, но на большой скорости сносятся.
- Reflection: шлейф из полупрозрачных силуэтов + призрак предыдущего забега,
  который повторяет прошлый маршрут (путь пишется в `localStorage`).
- Полный цикл: меню → игра → победа/проигрыш по таймеру → рестарт.

## Файлы

- `index.html` — разметка, HUD, оверлеи
- `style.css` — монохромный UI с красными акцентами
- `props.js` — материалы, фабрики объектов, генерация текстур с текстом
- `main.js` — сцена, уровень, физика, состояния игры

## Что осознанно упрощено

- Физика самописная и плоская (круг/AABB на плоскости XZ), без физдвижка.
- Разрушенное состояние генерируется из целого клонированием и «сплющиванием».
- Звук — короткие синтезированные всплески через WebAudio, без ассетов.
