# OFFBOARDING — веб-прототип офисного забега

Самостоятельная демка на Three.js. От Unity-проекта не зависит: своя папка, свои
файлы, ничего из `Assets/` не используется.

Цель — пощупать core loop (momentum + хватание и броски + разрушение + побег),
подачу главного меню и ночную визуальную стилистику до того, как это будет
собрано в Unity.

## Запуск

Нужен любой статический сервер (ES-модули не работают через `file://`):

```bash
python3 -m http.server 8123 --directory web-demos
```

Затем открыть <http://localhost:8123/office/>.

Three.js и постобработка (bloom) подтягиваются с unpkg через importmap, поэтому
при первом запуске нужен интернет. Если bloom не загрузился, демка сама
переключается на обычный рендер и продолжает работать.

## Управление

| Клавиша | Действие |
| --- | --- |
| `WASD` / стрелки | бег, простой сжигает momentum |
| `SHIFT` / `SPACE` | рывок: проходит сквозь стекло и машины, даёт неуязвимость |
| `E` / ЛКМ | контекстное хватание: нажать — схватить, нажать снова — бросить, удержать и отпустить — бросок сильнее |
| `F` / ПКМ | удар тем, что в руках; без предмета — пинок |
| `Q` | закурить |
| `R` | рестарт |
| `ESC` | закрыть оверлей |
| В меню | клик по ноутбуку или `ENTER` — играть, `H` — handbook |

## Что реализовано

Меню и подача:

- меню встроено в сцену: ноутбук = `PLAY`, планшет = `SETTINGS`, дверь = `QUIT`;
- стена с распечатками про замену сотрудников нейросетями;
- переворот стола как переход в игру, с пролётом камеры;
- коробка сразу оказывается в руках — первое обучение броску, цель — стеклянная
  дверь на выходе из кабинета.

Momentum:

- шкала растёт от разрушений и падает от простоя;
- влияет на скорость, силу броска и урон от тарана;
- сигареты (`Q`) резко поднимают momentum, замедляют падение шкалы и усиливают
  урон, после чего наступает короткий `crash` с ускоренным падением.

Reflection:

- призрак повторяет действия героя с задержкой ~2.2 секунды;
- добивает объекты, которые игрок уже повредил, и бьёт врагов;
- активен, пока momentum выше порога.

Оружие и предметы:

- лёгкие, средние и тяжёлые предметы: лёгкие носятся свободно, средние замедляют,
  тяжёлые только опрокидываются ударом;
- компьютерные мыши собираются до четырёх штук, радиус удара растёт с каждой,
  четыре можно метнуть одним клубком, провода рисуются линиями;
- пачка бумаги стреляет веером сюрикенов и кончается, после чего её саму можно
  бросить.

Противники:

- роботы-пылесосы: подсветка перед атакой, разгон, таран, выбивают предмет из рук,
  после промаха врезаются в мебель;
- дроны охраны: сбиваются рывком и на высокой скорости;
- серверная стойка как мини-босс: сканирующий луч, залпы дисков, импульс вблизи,
  после уничтожения остаётся искрящимся корпусом.

Уровень:

1. стартовый кабинет и меню;
2. open space со столами и пылесосами;
3. стеклянная переговорная;
4. серверная с боссом;
5. рецепция, турникеты и выход `EXIT`.

Полный цикл: меню → игра → победа или таймаут → рестарт.

## Файлы

| Файл | Ответственность |
| --- | --- |
| `props.js` | палитра, материалы, фабрики моделей, спеки предметов, текст на канвасе |
| `core.js` | общее состояние, урон и разрушение, снаряды, обломки, звук |
| `level.js` | геометрия уровня, зоны, точки спавна |
| `enemies.js` | пылесосы, дроны, босс |
| `main.js` | игрок, ввод, оружие, эхо, камера, свет, HUD, цикл |

Модули не образуют циклов: `props` ничего не импортирует, `core` знает только
`props`, `level` и `enemies` знают `core`, `main` собирает всё вместе.

## Визуальная стилистика

Ночной офис: почти чёрный фон, свет только пятнами, красный — единственный цвет.
Герой и мебель читаются силуэтами, красным подсвечены интерактив, тревога и
враги. Постобработка добавляет свечение красным элементам.

## Что осознанно упрощено

- Физика самописная и плоская (круг/AABB на плоскости XZ), без физдвижка.
- Разрушенное состояние генерируется из целого клонированием и «сплющиванием»,
  без реальной фрагментации.
- Провода мышей — просто линии, симуляции верёвок нет.
- Звук — короткие синтезированные всплески через WebAudio, без ассетов.
- Часть оружия из концепта (степлер, клавиатура, огнетушитель) пока работает как
  обычные метательные предметы.
