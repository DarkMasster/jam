# Веб-прототипы

Песочница для быстрых веб-демок отдельных механик и мини-игр. Каждая демка живёт
в своей подпапке и ни от чего не зависит: ни от Unity-проекта, ни от соседних
демок. Это черновики для проверки идеи, а не часть билда.

## Запуск

Один сервер на все демки:

```bash
python3 -m http.server 8123 --directory web-demos
```

<http://localhost:8123> — список демок, дальше по ссылкам.

## Демки

| Папка | Что проверяет |
| --- | --- |
| [`office/`](office/) | Offboarding: momentum, разрушение офиса, меню внутри сцены |

## Как добавить новую

1. Создать подпапку `web-demos/<название>/` со своим `index.html`.
2. Ничего не импортировать из соседних папок — демки не должны ломать друг друга.
3. Добавить строку в таблицу выше и карточку в `index.html` хаба.
4. Работать в отдельной ветке под конкретную демку, например
   `feature/web-demo-<название>`.

## Общий стиль

Держим единый визуальный язык концепта, чтобы демки складывались в одну картинку:

- почти монохром: фон `#e9e9e6`, чёрный `#121212`, серый `#8f8f8a`;
- красный `#b3241d` только для интерактива, тревоги и ключевых элементов;
- простые формы, никакой лишней детализации;
- 3D с ортографической камерой, логика движения по плоскости.
